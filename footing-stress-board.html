How the stress is calculated

Boussinesq's solution for a point load is integrated over each loaded area. Seen from the point P, a thin wedge of the footing between angles θ and θ + dθ, reaching out to a distance R(θ), adds

dσz = (q / 2π) [1 − (1 + R²/z²)−3/2] dθ

This is the same wedge idea Newmark used to build his chart. Going round the boundary of the footing and adding these wedges (with sign, so that points outside the footing and re-entrant corners are handled automatically) gives Δσz. For a straight edge at perpendicular distance h from P, the integral has a closed form, so the result for any polygon is exact. With a = h/z, c² = 1 + a² and φ the angle measured from the perpendicular to the edge,

∫ [1 − (1 + R²/z²)−3/2] dφ = φ − sin−1(sin φ / c) + a² sin φ / (c² √(c² − sin² φ))

Circles are treated as regular polygons with 512 sides, which changes the result by less than 0.001 %. For a rectangle the result matches the corner-factor formula exactly.

Shapes are combined in order, like layers. An Add shape is loaded with its q and replaces whatever load lies below it, so overlapping shapes merge into one footing instead of being loaded twice. A Subtract shape removes all load below it, leaving a hole. A Superpose shape adds its q to the load below, which is useful for a column load on top of a raft. The boundaries of the resulting loaded regions, including the edges of any holes, are found by polygon clipping, and the edge sum above is taken round every one of them. A hole's edges run the opposite way, so they subtract automatically.

The Newmark overlay draws the chart for the current depth: rings at R/z = √[(1 − Δσz/q)−2/3 − 1] for Δσz/q = 0.1, 0.2, … 0.9, and 20 rays, so each block is worth 0.005. Counting blocks inside a footing and multiplying by 0.005 approximates the influence factor I that the calculator gives exactly.
